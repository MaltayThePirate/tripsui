# Area A: Trip Management

User stories covering trip creation, date ranges (Trip Window), configuration, and membership.

## Stories

### R1-A-01: Create a Trip
- **Status:** ✅ Done
- **Role:** Trip Planner
- **FR Mapping:** FR-3
- **Description:** As a Trip Planner, I can create a Trip with a name and a date range (Trip Window), so my group has a shared container to plan around.

### R1-A-02: Edit Trip Window
- **Status:** 🟡 Partial (Creation done; edit flow pending)
- **Role:** Trip Planner
- **FR Mapping:** FR-3
- **Description:** As a Trip Planner, I want to edit the Trip Window after creation, in case our travel dates change.

### R1-A-03: Trip Collaboration & Membership
- **Status:** ✅ Done
- **Role:** Member (Trip Planner / Traveler)
- **FR Mapping:** PRD Section 2
- **Description:** As any Member, I can join a Trip and act as a Trip Planner, a Traveler, or both, without the product forcing me into a single fixed role.
