# Area B: Spots & Categories

User stories covering spot creation via Google/Apple Maps links, geocoding, spot notes, starter categories, and custom categories.

## Stories

### R1-B-01: Spot Creation via Maps Link
- **Status:** ✅ Done
- **Role:** Trip Planner
- **FR Mapping:** FR-1
- **Description:** As a Trip Planner, I can paste a Google or Apple Maps link to add a Spot, without manually typing an address, so adding places is fast and accurate.

### R1-B-02: Spot Geocoding Validation & Error Handling
- **Status:** ✅ Done
- **Role:** Trip Planner
- **FR Mapping:** FR-1
- **Description:** As a Trip Planner, I can see an error and have nothing created if my pasted link isn't a recognized Maps link or fails to geocode, so I'm not left with a broken, unlocated Spot.

### R1-B-03: Spot Notes
- **Status:** ✅ Done
- **Role:** Trip Planner / Traveler
- **FR Mapping:** FR-2a
- **Description:** As a Trip Planner, I can add a free-text note to any Spot, and so can any other Member, so we can leave tips like "get there before 6pm" for the group.

### R1-B-04: Starter & Custom Categories
- **Status:** ✅ Done
- **Role:** Trip Planner
- **FR Mapping:** FR-2
- **Description:** As a Trip Planner, I see a starter set of Categories already available on a new Trip, and I can create a custom Category that every other Member can immediately see and use.

### R1-B-05: Multi-Category Assignment
- **Status:** ✅ Done
- **Role:** Trip Planner
- **FR Mapping:** FR-2
- **Description:** As a Trip Planner, I can assign a Spot to more than one Category, since a place like a bar that's also a restaurant doesn't fit neatly into one bucket.

### R1-B-06: Rich Spot Details at a Glance
- **Status:** ✅ Done
- **Role:** Traveler
- **FR Mapping:** FR-1, FR-2, FR-2a
- **Description:** As a Traveler, I can see a Spot's photo, address, note, and Categories at a glance, so I have enough context to decide whether to go.
