# Release 1 User Stories Overview

This directory contains the user stories for Release 1 of Wander, organized by product area (`A` through `F`). Each user story is keyed with release and product area identifiers (e.g., `R1-A-01`) for precise tracking across documentation, implementation plans, and GitHub issues.

## Product Areas

- **[Area A: Trip Management](A-trip-management.md)** (`R1-A-xx`) — Trip creation, date range (Trip Window) management, edit flows, and membership.
- **[Area B: Spots & Categories](B-spots-and-categories.md)** (`R1-B-xx`) — Spot creation via map links, geocoding, spot notes, starter categories, and custom categories.
- **[Area C: Accommodations & Flights](C-accommodations-and-flights.md)** (`R1-C-xx`) — Per-member flights, accommodation date ranges, overlap warnings, and active accommodation selection.
- **[Area D: Map View](D-map-view.md)** (`R1-D-xx`) — Visual mapping of spots and accommodations.
- **[Area E: Day Plans & Shared View](E-day-plans-and-shared-view.md)** (`R1-E-xx`) — Personal day plan assignments, drag-and-drop ranking, and derived multi-member shared views.
- **[Area F: Exports & Offline](F-exports-and-offline.md)** (`R1-F-xx`) — Offline viewing and copy-to-clipboard itinerary exports.
