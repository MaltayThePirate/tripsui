# Area F: Exports & Offline

User stories covering category exports, offline viewing, and copy-to-clipboard itinerary message sharing.

## Stories

### R1-F-01: Google Maps Category Export
- **Status:** 🚫 Backlogged
- **Role:** Trip Planner
- **FR Mapping:** FR-7
- **Description:** As a Trip Planner, I can select a Category and export every Spot in it to Google Maps, regardless of what day (or whether) it's been planned. *(Backlogged: awaiting Google Maps write API support per Issue #453378725).*

### R1-F-02: Offline Day Plan Viewing
- **Status:** ⬜ Not started
- **Role:** Traveler
- **FR Mapping:** FR-8
- **Description:** As a Traveler, I can view my Day Plan or the day's Shared View as a plain text list (name, address, note, Category) with no network connection, satisfied indirectly via copy-to-clipboard export.

### R1-F-03: Shared Itinerary Message Export (Copy-to-Clipboard)
- **Status:** ⬜ Not started
- **Role:** Traveler
- **FR Mapping:** FR-9
- **Description:** As a Traveler, I can export a Day Plan or Shared View as a copyable, shareable text message (name, address, Category), so I can paste it into Notes, Messages, or email before heading out.
