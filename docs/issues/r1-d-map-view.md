# [R1-D-01] Map View with Google Maps JS SDK

- **Product Area:** Area D (Map View)
- **User Story:** R1-D-01
- **Functional Requirement:** FR-5
- **Status:** ✅ Completed

## User Story
As a Trip Planner, I can view all my Trip's Spots and relevant Accommodations together on a map, so I can visually judge which Spots cluster together.

## Acceptance Criteria
- [x] Integrate Google Maps JavaScript SDK into `tripsui` Map View component.
- [x] Replace mockup percentage-based pins with real geocoded latitude/longitude markers for Spots and Accommodations.
- [x] Support visual inspection of proximity (no automatic clustering in MVP).
