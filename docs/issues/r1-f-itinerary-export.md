# [R1-F-03] Shared Itinerary Message Export

- **Product Area:** Area F (Exports & Offline)
- **User Story:** R1-F-03
- **Functional Requirement:** FR-9
- **Status:** ⬜ Not Started

## User Story
As a Traveler, I can export a Day Plan or Shared View as a copyable, shareable text message (name, address, Category), so I can paste it into Notes, Messages, or email before heading out.

## Acceptance Criteria
- [ ] Frontend action to format a selected Day Plan or Shared View into a plain-text summary (Spot name, address, category).
- [ ] Copy-to-clipboard functionality using browser Clipboard API.
- [ ] Export disabled or showing error when exporting a plan with zero spots.
- [ ] Supports offline reference needs (satisfying FR-8 indirectly).
