# Issue Tracker

Issues are tracked as markdown files under `docs/issues/` in this project repository.

## Commands

- **List issues**: `ls docs/issues/`
- **Read issue**: Read the markdown file under `docs/issues/` directly.
- **Create issue**: Create a new markdown file under `docs/issues/`.
- **Update issue / Apply label**: Edit the markdown file under `docs/issues/` or update its frontmatter/status.

## PRs as a request surface

- **Enabled**: `false`
